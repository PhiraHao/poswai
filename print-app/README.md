# POS WAI ตัวพิมพ์ — แอปสำหรับ iPhone, iPad และ Android

แอปตัวเล็ก ๆ ที่ทำหน้าที่เดียว: คอยรับใบเสร็จจากคิวของร้าน แล้วพิมพ์ออก
เครื่องพิมพ์ Bluetooth ที่อยู่ในร้าน

ร้านไม่ต้องมีคอมพิวเตอร์หรือกล่องอะไรเพิ่ม ใช้มือถือหรือไอแพดเครื่องที่
ใช้ขายอยู่แล้วเปิดแอปนี้ค้างไว้

```
มือถือ/ไอแพดของใครก็ได้ในร้าน ──กดพิมพ์──► POS WAI (คิวงานพิมพ์)
                                                  │
                            แอปนี้ (เปิดค้างไว้) ◄─┘
                                                  │ Bluetooth
                                             เครื่องพิมพ์
```

## ตั้งค่าครั้งแรก

1. **ขอกุญแจ** — เข้า POS WAI ด้วยบัญชีเจ้าของร้าน → แท็บแคชเชียร์ → กล่อง
   **🖨️ เครื่องที่เสียบปริ้นเตอร์ไว้** → **+ เพิ่มเครื่องพิมพ์** → กดปุ่ม 📋 ก๊อปกุญแจ
2. **เปิดแอปนี้** → ใส่ชื่อร้านในลิงก์กับกุญแจ → กดบันทึก
3. **กดค้นหาเครื่องพิมพ์** → เลือกชื่อที่ขึ้น (เช่น POS58_49C4)
4. **กดพิมพ์ใบทดสอบ** ว่าออกจริง
5. **กดเริ่มรับงานพิมพ์** แล้วเปิดแอปค้างไว้

## รองรับเครื่องพิมพ์อะไรบ้าง

แอปลองช่องรับข้อมูลที่เครื่องพิมพ์ความร้อนนิยมใช้ทั้งหมดตามลำดับ
(`18F0`/`2AF1`, `FF00`/`FF02`, `FEE7`/`FEC7`, ISSC `49535343`,
Microchip `E7810A71`, `FFE0`/`FFE1`) ครอบคลุมเครื่อง 58 มม. และ 80 มม.
แบบพกพาที่ขายกันทั่วไป

**ข้อจำกัดที่เปลี่ยนไม่ได้:** iPhone กับ iPad คุยกับ Bluetooth แบบเก่า
(Classic/SPP) ไม่ได้เลย — Apple เปิดให้เฉพาะอุปกรณ์ที่ผ่านโครงการ MFi
เครื่องพิมพ์ที่เป็น Classic อย่างเดียวจึงใช้ได้แต่บนแอนดรอยด์
เครื่องที่ขายกันตอนนี้ส่วนใหญ่มี Bluetooth LE มาด้วย จึงใช้ได้ทั้งสองระบบ
(POS58 ที่ร้านใช้อยู่มีทั้งสองแบบ ตรวจแล้ว)

## ภาษาไทยพิมพ์ยังไง

ส่งเป็น **รูป** ไม่ใช่ตัวอักษร เพราะเครื่องพิมพ์ราคาถูกมีชุดตัวอักษรจีน
ส่วนโค้ดเพจไทยแล้วแต่โรงงาน — เครื่องที่ร้านใช้อยู่ลองมาแล้วทุกรหัสตั้งแต่
20 ถึง 255 ภาษาไทยหายหมดเหลือแต่ตัวเลข

แอปวาดใบเสร็จลง canvas ด้วยฟอนต์ไทยของเครื่อง แล้วส่งเป็นคำสั่ง **ESC \***
ทีละแถบ 24 จุด (ไม่ใช่ GS v 0 ซึ่งเครื่องรุ่นนี้ทำได้ไม่นิ่ง)

## ทดลองบนคอมก่อนสร้างแอป

```
npm run serve
```

เปิด http://localhost:5190 ด้วย **Chrome บนคอมหรือแอนดรอยด์** จะใช้ Web
Bluetooth ของเบราว์เซอร์แทน ทดสอบได้ครบทุกอย่างโดยไม่ต้องสร้างแอป
(Safari ไม่รองรับ จึงต้องสร้างเป็นแอปสำหรับ iPhone)

## สร้างเป็นแอป

```
npm install
```

```
npx cap add android
```

```
npx cap add ios
```

```
npm run sync
```

จากนั้นเปิดด้วย `npm run android` หรือ `npm run ios`

สิ่งที่ต้องใส่เพิ่มในโปรเจกต์เนทีฟ:

- **iOS** — `Info.plist` ต้องมี `NSBluetoothAlwaysUsageDescription`
  เช่น "ใช้เชื่อมกับเครื่องพิมพ์ใบเสร็จของร้าน"
- **Android** — `AndroidManifest.xml` ต้องมี `BLUETOOTH_SCAN` กับ
  `BLUETOOTH_CONNECT` (Android 12 ขึ้นไป) และ `ACCESS_FINE_LOCATION`
  สำหรับรุ่นเก่ากว่านั้น

## ทดสอบส่วนคำนวณ

```
npm test
```

แบ่งข้อมูลเป็นก้อนเท่าที่ Bluetooth รับไหว — ทั้งหมดรันด้วย node ไม่ต้องมี
เครื่องพิมพ์
